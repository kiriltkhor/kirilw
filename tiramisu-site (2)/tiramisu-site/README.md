# Тіра Мі Су — сайт про тірамісу

Одно­сторінковий сайт про тірамісу для молодіжної аудиторії: історія десерту, чотири смаки, замовлення та форма питань.

## Як відкрити

Відкрий `index.html` у браузері. Нічого встановлювати не потрібно. Шрифти підтягуються з Google Fonts, тож для точного вигляду потрібен інтернет.

## Структура

```
index.html        сторінка з 7 секціями
css/styles.css    стилі (темна й світла теми за налаштуванням системи)
js/main.js        вибір інгредієнта на схемі шарів і відповідь форми
images/           8 SVG-ілюстрацій
tools/            скрипт, яким згенеровано ілюстрації
```

## Секції

| № | Секція    | id         | Що всередині                                                    |
|---|-----------|------------|-----------------------------------------------------------------|
| 1 | Header    | `top`      | логотип, навігація, соцмережі, CTA «Замовити тірамісу»          |
| 2 | Hero      | `hero`     | заголовок, слоган, головне зображення, CTA                      |
| 3 | About     | `about`    | історія, 4 факти, інтерактивний склад, емоційна складова, користь |
| 4 | Products  | `products` | 4 картки смаків із фото, описом, ціною й кнопкою «Купити»       |
| 5 | Order     | `order`    | 4 кроки, мокап застосунку, посилання на App Store й Google Play |
| 6 | Contact   | `contact`  | форма питань з мотивуючим заголовком                            |
| 7 | Footer    | —          | навігація, контакти, адреса, години роботи, соцмережі, копірайт |

## Що враховано

- HTML5, `lang="uk"`, семантичні теги, один `h1`, заголовки по порядку
- усі зображення мають змістовний `alt`, `width` і `height`
- зовнішні посилання мають `target="_blank"` і `rel="noopener noreferrer"`
- кожне поле форми має `label`, обов'язкові поля позначені `required`
- сайт працює на телефоні: сітки перебудовуються, горизонтального скролу немає
- без JavaScript сайт теж читається: інтерактивна схема просто показує всі шари
- `prefers-reduced-motion` вимикає анімацію наведення

## Про вигадані дані

Назва, адреса, телефон, пошта (`.example`) і ціни вигадані. Форма нікуди не надсилає дані, а посилання на соцмережі й магазини застосунків ведуть на головні сторінки сервісів.

## Git
