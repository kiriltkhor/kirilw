# Сайт про [Назва вашої тваринки]
Коргі
## Опис проекту
Цей вебсайт є яскравішою односторінковою фан-енциклопедією про собачок породи вельш-коргі, що містить їхній опис, цікаві факти, корисні посилання та поради щодо харчування. Також на сторінці розміщено зручне меню навігації та інтерактивну форму опитування для відвідувачів.

## Структура сайту
- index.html - Головна сторінка з фактами про тваринку
- story.html - Історії та легенди

## Використані технології
- HTML5
- Семантична розмітка
- Форми з валідацією
